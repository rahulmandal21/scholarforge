# ScholarForge Backend

FastAPI backend for ScholarForge — an agentic research-to-code pipeline.
Takes a research paper PDF and produces parsed structure, a component
breakdown, a knowledge graph, generated code, and related resources.

See the main repo for the full project: https://github.com/rahulmandal21/scholarforge
